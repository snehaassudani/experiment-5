# experiment-5

### Aim

To write a Python program to demonstrate various tuple operations such as accessing elements, finding length, counting occurrences, finding index positions, and calculating maximum, minimum and sum. The program also demonstrates converting a tuple into a list and a list back into a tuple.

### Algorithm

1. Start the program.
2. Create a tuple named `t` containing the elements 10, 20, 30, 20 and 40.
3. Display the original tuple.
4. Access and display the first element using positive indexing.
5. Access and display the last element using negative indexing.
6. Find and display the length of the tuple using `len()`.
7. Count the occurrences of 20 using `count()`.
8. Find the index position of 30 using `index()`.
9. Find and display the maximum value using `max()`.
10. Find and display the minimum value using `min()`.
11. Calculate and display the sum of all elements using `sum()`.
12. Check whether 40 is present in the tuple using the `in` operator.
13. Convert the tuple into a list using `list()` and display it.
14. Convert the list back into a tuple using `tuple()` and display it.
15. Stop the program.

### Output:

Tuple: [10, 20, 30, 20, 40]
First element: 10
Last element: 40
Length: 5
Count of 20: 2
Index of 30: 2
Maximum: 40
Minimum: 10
Sum: 120
Is 40 present? True
Tuple converted to list: [10, 20, 30, 20, 40]
List converted to tuple: (10, 20, 30, 20, 40)
